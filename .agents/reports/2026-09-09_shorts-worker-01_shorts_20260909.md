## 4. Napotkane przeszkody i rozwiązania techniczne

1. **Brak domyślnych wartości `start_sec`/`end_sec` w `DescribeRequest`**:
   - `DescribeRequest` w `vse-api` bezwzględnie wymagał `start_sec: float` i `end_sec: float` (błąd HTTP 422).
   - *Rozwiązanie:* Zaktualizowano `process_shorts_describe.py` o przekazywanie `start_sec: 0.0` oraz `end_sec: 300.0`.
2. **Brak plików VTT dla bezpośrednio wgranych shortów**:
   - Shorty wgrane bezpośrednio do YouTube Studio nie miały wpisów w `TranscriptJob` ani na dysku VPS (`/tmp/{id}.vtt`).
   - *Rozwiązanie:* Rozbudowano `process_shorts_describe.py` o automatyczne pobieranie napisów VTT ASR bezpośrednio z YouTube API przez aktywne konto kanału `Studio Prawy_PL` przed wywołaniem `/v1/shorts/describe`.
3. **Komentarze przypięte dla filmów prywatnych**:
   - YouTube Data API odrzuca dodawanie komentarzy do filmów ze statusem `private` (HTTP 403 - insufficient permissions). Komentarz został z sukcesem dodany do filmu publicznego (`lX2vvs8E-AY`), natomiast dla filmów zaplanowanych komentarze zostaną opublikowane po ich przejściu w status publiczny.
